# Persona-Discovery


 We propose **TriPer-MRL**, which extends TriPer with Matryoshka representation learning. We study further whether LLMs can retrieve and discover personas directly from user interaction data.

## Overview

- **TriPer-MRL**: a tripartite graph neural network trained with a Matryoshka learning to produce nested representations.
- **Extended persona taxonomy**: Extended personas taxonomy.
- **LLM-based persona pipeline**:
  - *Persona retrieval*: a fine-tuned retrieval LLM that assigns personas to users from the extended taxonomy.
  - *Persona discovery*: discovering personas not in the existing taxonomy.
